# Нужны ли нейросети? Анализ

> Этап 0 (2026-09-29). Тикет: T-0003.

## Вывод коротко

* **Для ядра — нет.** Цветовой баланс, насыщенность и сведение серии к референсу
  решаются классической колориметрией (Lab-статистика + решатель по ползункам,
  см. [ALGORITHM.md](ALGORITHM.md)). Это быстро, детерминированно, объяснимо и даёт
  результат в обычных ползунках.
* **Для «умной пипетки» — да, маленькие специализированные модели (опционально).**
  Они повышают качество там, где статистика ошибается: сюжетные цвета путаются с
  цветовым кастом, а кожа людей должна совпадать особенно точно.
* **LLM/VLM — не нужны для матчинга.** Максимум — необязательная «подсказка»
  (описать сцену, предложить настроение) через локальный LM Studio. Низкий приоритет.

## Разбор вариантов

| Модель | Зачем | Цена | Решение |
|---|---|---|---|
| Детектор лиц (YuNet ONNX, ~0.3 МБ, есть прямо в OpenCV `FaceDetectorYN`) | Якорь «кожа»: сравнивать цвет лиц реф ↔ цель | Почти бесплатно, CPU | **Берём** (этап 4, T-0016) |
| Семантическая сегментация (SegFormer-B0/B2 ADE20K → ONNX) | Маски «небо», «растительность», «стены», «люди» — исключать сюжетные цвета из оценки каста, матчить по классам | ~15–100 МБ, GPU/CPU, 20–100 мс/кадр | **Берём опционально** (этап 4, T-0016) |
| Карта глубины: Depth Anything V2 Small/Base (ONNX), альт. Depth Pro | Маски «ближе/дальше» для регионов (T-0032), отделение дали/неба, матчинг «план к плану», воздушная перспектива | 25–100 М параметров, GPU ~10–40 мс на прокси | **Берём** на этапе 7 (T-0033) |
| SAM 2 / MobileSAM (click-to-mask) | Пипетка «кликни по объекту → точная маска объекта» | 40–200 МБ, GPU | **Идея**, после базовой пипетки (T-0015) |
| Нейро-перенос цвета (Deep Color Transfer, PhotoWCT и т. п.) | Прямой перенос «стиля» | Результат не выражается ползунками, артефакты, нельзя докрутить | **Не берём** |
| VLM (Qwen-VL и др. через LM Studio) | Описание сцены, «сделай теплее, как вечер» → параметры | Медленно, недетерминированно | **Идея**, низкий приоритет |

## Инфраструктура

* Рантайм — `onnxruntime-gpu` (RTX 5090 есть), фолбэк `onnxruntime` на CPU.
* Модели кладутся в `models/` (в `.gitignore`), скачиваются командой
  `colormatch models download`. Без моделей всё работает — просто без семантических якорей.
* Маски считаются один раз на прокси и кешируются в воркспейсе.
