# Дизайн интерфейса

> Этап 0 (2026-09-29). Тикеты: T-0022…T-0028.

## 1. Раскладка главного окна (после правок T-0037…T-0040)

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ Меню · Тулбар: Открыть Сохранить | +Папка +Фото | ★Реф ⚖Авто | 1 2 3 4 ◎ | ◐До(Z) ★Реф(X) | Экспорт ⚙ │
├──────────────┬────────────────────────────────────────────────────────────────┤
│ РЕФЕРЕНСЫ    │ [ref]   │ КАДРЫ СЦЕНЫ: <сцена>                                  │
│ общие/сцены  │ (1–2,   │ [кадр][кадр][кадр][кадр] …  ← один блок сверху,       │
│ ▣▣▣ S 41     │ по числу)│                               не открепляется         │
├──────────────┴─────────┴──────────────────────────────────────┬─────────────────┤
│ ВОРКСПЕЙС    │               ПРОСМОТР (фон — цвет темы)        │ Правки │ Авто │ │
│ ▾ Сцена A    │  1 одно │ 2 до/после │ 3 рядом │ 4 пипетка       │ Пресеты          │
│   ├ img01    │  Z (держать) — «до», X (держать) — референс     │ ползунки …       │
│ ▾ Сцена B    │                                                │                 │
└──────────────┴────────────────────────────────────────────────┴─────────────────┘
```

* Верхний блок — референсы (узкий, ширина по числу: обычно 1–2 миниатюры, до 3, дальше прокрутка)
  и кадры текущей сцены в одной строке. Блок нельзя закрыть, открепить или сдвинуть.
* Слева — дерево воркспейса, справа — вкладки «Правки / Авто-баланс / Пресеты»; эти две
  панели можно откреплять и прятать (меню «Вид»).
* Фон просмотра по умолчанию — цвет темы; нейтральный серый 18% (для точной работы с цветом),
  чёрный, белый, шахматка — в настройках.
* Режим «рядом с референсом» — основной для ручной докрутки: слева реф, справа цель.

## 2. Одиночное и групповое редактирование

* Выделение: клик, Ctrl+клик, Shift+клик, Ctrl+A в ленте/дереве; выделение сцены целиком.
* Панель настроек показывает **текущее** фото. Если выделено несколько —
  режим группы: ползунки показывают общее значение или «—» при расхождении.
  Движение ползунка в группе:
  * **Абсолютно** (всем то же значение) или
  * **Относительно** (+Δ к значению каждого) — переключатель у панели.
* Удаление из воркспейса: `Del` (с подтверждением для группы, с Undo). Файлы на диске
  не удаляются.
* Undo/Redo (`Ctrl+Z` / `Ctrl+Shift+Z`) для всех правок параметров и состава.

## 3. Добавление фото

| Способ | Поведение |
|---|---|
| Меню «Импорт папки» | Рекурсивно; **каждая подпапка = сцена** (имя сцены = относительный путь) |
| «Импорт файлов» | Один/несколько файлов в текущую сцену |
| Drag & Drop | Файлы и папки из проводника (папки — как импорт папки) |
| `Ctrl+V` | Из буфера: список файлов (скопированных в проводнике) **или** растровое изображение (сохраняется в `<workspace>/_pasted/`) |
| `Ctrl+C` | Копирует выделенные фото в буфер **как файлы** (рендер с правками во временную папку) + одиночное — ещё и как изображение |

Пресеты копипастятся отдельными командами: `Ctrl+Shift+C` — копировать параметры,
`Ctrl+Shift+V` — вставить параметры в выделенные (с диалогом «какие группы параметров»).

## 4. Скины/темы

* Тема = JSON-палитра токенов (`bg`, `bg_alt`, `panel`, `border`, `text`, `text_dim`,
  `accent`, `accent_hover`, `danger`, `slider_groove`, …) + единый QSS-шаблон.
  Новая тема = один JSON-файл, пользовательские — в `%APPDATA%/colormatcher/themes`.
* Встроенные темы (≥ 16, большинство тёмные):
  **Moonlight** (фирменная, серебро+изумруд), **Midnight Emerald**, **OLED Black**,
  **Graphite**, **Darkroom Red** (для работы с цветом ночью), **Nord**, **Dracula**,
  **Tokyo Night**, **Catppuccin Mocha**, **One Dark**, **Gruvbox Dark**,
  **Solarized Dark**, **Monokai**, **Neutral Gray 18%** (нейтральная для цветокоррекции);
  светлые: **Paper**, **Solarized Light**, **Catppuccin Latte**.
* Нейтральный фон просмотра настраивается отдельно от темы (серый 18%, чёрный,
  белый, шахматка) — чтобы тема не искажала восприятие цвета.

## 5. Масштаб и шрифты

* Масштаб интерфейса: 75–250% (через `QT_SCALE_FACTOR` при старте + мгновенный
  пересчёт размеров шрифтов/отступов в QSS-шаблоне).
* Семейство и размер шрифта UI, отдельно — размер подписей ползунков.
* Размер миниатюр в ленте/референсах — ползунок.
* Всё сохраняется в `settings.json` (`%APPDATA%/colormatcher`).

## 6. Ползунки

* Ползунок + числовое поле; двойной клик — сброс в 0; колесо — ±1, Shift+колесо — ±10.
* Градиентная подложка у Color Balance (cyan→red и т. д.) — видно направление;
  у Brightness — от тёмного к светлому, у Contrast — от плоского к контрастному.
* Живое превью с троттлингом (перерисовка LUT по таймеру ~16 мс).

## 7. Реализовано (этап 4, 2026-09-29)

Код — `colormatcher/gui/`. Запуск — `colormatch-gui.bat` (или `python -m colormatcher.gui [файл.cmws]`).

* Раскладка §1: лента референсов (всегда видна, без закрытия) с плашками целевого профиля
  (оттенок нейтралей теней/середин/светов + насыщенность), дерево воркспейса, лента кадров
  сцены, справа вкладки «Правки / Авто-баланс / Пресеты». Раскладка док-панелей сохраняется.
* Просмотр: **1** одно фото, **2** до/после (шторка тянется мышью), **3** рядом с референсом,
  **4** «что видит пипетка» — подсветка пикселей, учтённых как нейтрали (с голосами плиток).
  Колесо — масштаб, перетаскивание — панорама, двойной клик — вписать/100%.
* **Пипетка-якоря** (◎, клавиша **A**): в режиме «рядом с референсом» обвести объект на
  референсе, затем тот же объект на текущем фото → пара-якорь (метка: «кожа», «стена»…)
  сохраняется в фото и учитывается авто-балансом. Якоря рисуются рамками.
* Правки: ползунки строятся из реестра фильтров; Color Balance — тени/середины/света (точка •
  у диапазона с правками); группа — абсолютно или относительно (+Δ), расхождение — «—»;
  галочка группы — вкл/выкл фильтра; двойной клик — сброс; колесо ±шаг×чувствительность,
  Shift ×10, Ctrl ×0.1.
* Undo/Redo для всего: перетаскивание ползунка — один шаг; авто-баланс — один шаг.
* Авто-баланс и экспорт — в фоне (окно не замирает).
* Импорт: меню, drag&drop файлов и папок (подпапки = сцены), Ctrl+V (файлы из проводника
  или картинка — сохраняется в `_pasted/`). Ctrl+C — выделенные фото с правками как файлы
  (одно — ещё и как картинка).
* Темы: 17 (13 тёмных + нейтральная 18% + 3 светлые), смена на лету; настройки: шрифт,
  размер, подписи ползунков, миниатюры, фон просмотра, масштаб интерфейса (после перезапуска),
  чувствительность колеса, автосохранение.
* Автосохранение: раз в N минут в `<имя>.autosave.cmws`; при открытии, если оно свежее, —
  предложение восстановить; после «Сохранить» удаляется.

### Правки после теста №2 (T-0041…T-0050)

* **Референсы (T-0050):** в ленте все референсы проекта, активный — с ●; клик — сделать
  активным, двойной клик — открыть для правки. Режимы «рядом», удержание X и якоря берут
  референс текущего фото (по которому оно подбиралось), иначе активный.
* **Авто-баланс:** «выделенные» (B) — по активному; «сцена» / «весь проект» — каждому свой.
  Прогресс «N из M» — в панели, в строке состояния и плашкой на просмотре (T-0045).
* **Ползунки (T-0046, T-0048, T-0049):** клик по линии — значение в точку клика;
  Ctrl+клик — шаг 10 к точке, Shift+клик — шаг 20; перетаскивание с Ctrl/Shift — прилипание
  к 10/20; колесо — шаг из настроек, Ctrl ±10, Shift ±20. Все линии одной длины. У
  несимметричных диапазонов (контраст −50…+100) ноль посередине: каждая половина — своя сторона.
* **Выделение (T-0044):** Shift+клик и стрелки в ленте — строго по порядку кадров;
  переключение ~12 мс (кеш готовых кадров, кеш масштабирования на просмотре).
* **Иконка и exe (T-0041, T-0042, T-0051):** красная луна из `icon.jpg` (`gui/icons/moon.png|ico`, вырезка и центровка —
  `tools/make_icon.py`); `ColorMatcher.exe` в корне — постоянная обёртка
  (`tools/launcher/ColorMatcher.cs`, сборка `tools/build_launcher.bat` компилятором C# из Windows).
* **Закрепление на панели задач (T-0052):** окну при запуске записываются свойства повторного запуска
  (`gui/winshell.py`): команда — `ColorMatcher.exe`, имя, иконка `moon.ico`; закреплённая кнопка — с луной.
* **Запуск (T-0054):** открывается последний воркспейс из «Недавних» (если файл есть; галочка в настройках).
* **Дерево и лента (T-0055):** корень «Все фото (N)» → папки (подпапки импорта) → фото. Клик по корню — в ленте все
  фото из всех подпапок; по папке — её кадры (подсвечено в дереве). Клик по корню/папке выделение не меняет;
  Ctrl+A — выделить все кадры ленты. При открытии воркспейса лента показывает всё.

### Маски, этап М1 (T-0058…T-0060, T-0064)

* Кнопка **«Маски»** после «Одно» (клавиша M). Кадр — как в «Одно», поверх — полупрозрачный слой меток.
  Рисуется на текущем фото; референс — открыть двойным кликом в ленте референсов и рисовать так же.
  **X** в режиме масок — референс вместе с его масками.
* Справа над «Настройками фото» — **панель масок** (видна только в режиме):
  палитра из 7 цветов + служебные «не учитывать» (штриховка) и «не трогать» (клетка);
  кисть/ластик, диаметр (px сетки маски, длинная сторона 1024), жёсткость, нажим, прозрачность оверлея,
  «показывать только выбранную метку»; **список масок фото**: цвет, площадь на кадре и на референсе,
  ✎ — рисовать этой меткой, ✕ — удалить метку с фото; крошечные области (< 0.2%) — с ⚠.
* Контур кисти под курсором (пунктир — ластик). Каждый мазок — отдельный шаг Ctrl+Z.
* Пресет палитры — «Настройки → Палитра масок» («Спокойная», «Пастель», «Глубокая», «Различимая»);
  метки хранятся по номеру, смена палитры меняет только отображение.

### Правки после теста М1 (T-0067…T-0072)

* **Зум колесом под курсором (T-0067):** точка кадра под мышью остаётся на месте; вокруг кадра — поля сцены,
  поэтому якорь работает и когда кадр меньше окна; полос прокрутки нет (панорама — перетаскиванием,
  в режиме масок — средней кнопкой). Alt+колесо тоже приближает/отдаляет (T-0072).
* **Панель масок в один ряд (T-0068, T-0069):** иконки кисти и ластика, 7 цветов, «не учитывать», «не трогать» —
  без текста, названия во всплывающих подсказках. Ниже — ползунки кисти и оверлея.
* **[ ] и Shift+[ ] (T-0070)** — размер и жёсткость, по физической клавише (любая раскладка).
* **Сплошной мазок (T-0071):** см. «Кисть» в MASKS-DESIGN — «червячок» по траектории без бусин, нажим ровный.
* В режиме масок двойной клик не переключает «вписать/100%» — быстрые клики остаются мазками.
* **Ползунки панели масок (T-0073)** — те же, что в «Настройках фото»: клик — значение в точку,
  Ctrl/Shift — шаг 10/20, колесо, правый/двойной клик — сброс к значению по умолчанию.
* **Кисть: диаметр + распределение (T-0075, заменил «Спад» T-0074)** — жёсткость и нажим из панели убраны
  (всегда 0 и 100%); «Распределение» 0…100%: кисть всегда на весь диаметр, 0% — плотное ядро ~10% диаметра и
  плавный видимый спад до края, 100% — почти сплошной диск. Справа — превью отпечатка с кривой. Shift+[ ] — распределение ±10%.
* **Окно на небольших экранах (T-0079):** вкладки «Авто-баланс», «Пресеты» и панель масок — с прокруткой;
  граница «панель масок / вкладки» перетаскивается; окно при запуске ограничено видимой областью экрана.
  Минимальная высота окна ~410 px (в режиме «Маски» ~500 px) вместо ~770 / ~1150.

### Маски, этап М2 (T-0061, T-0062, T-0065)

* **«Настройки фото» по цветам масок:** над ползунками — «Общее» и кружки цветов меток выделенных фото
  (точка — у слоя есть правки). Выбран цвет — ползунки правят слой этой метки (только под маской, поверх общих);
  подсказка под переключателем напоминает, что правится. «Сбросить» — сброс выбранного слоя.
* Кадр в просмотре, миниатюры и экспорт — с учётом слоёв; после мазка кадр перерисовывается.
* В режиме «Маски» миниатюры референсов показывают маски.

### Маски, этап М3 (T-0063)

* «Авто-баланс» → галочка **«Учитывать маски: слой на каждую метку»**. Авто-баланс заполняет слои меток
  (видны в «Настройках фото» при выборе цвета — их можно докрутить) и не смотрит на «не учитывать»/«не трогать».
* Таблица результатов: «меток: N»; подсказка строки — ползунки и сходимость по каждой метке.
* Кеш миниатюр держит несколько вариантов на фото (с масками для ленты референсов и без — для ленты кадров),
  иначе ленты вытесняли варианты друг друга и миниатюры мигали (T-0080).
* **«Фон» (T-0082):** кнопка между «Общее» и цветами — правки всего, что не закрашено метками (поверх общих);
  «Фон •» — у слоя есть правки. Только вручную: авто-баланс его не трогает.

### Язык, вкладки настроек, горячие клавиши (T-0083, T-0084, T-0085)

* **Язык интерфейса:** английский (по умолчанию) и русский; «Настройки → Основные → Язык», применяется сразу
  после закрытия настроек — окно пересобирается с тем же воркспейсом, Undo и видом (T-0086).
  Файлы языков — JSON в `gui/lang/` и `%APPDATA%/colormatcher/lang/` (как добавить язык — docs/I18N.md).
* **Настройки по вкладкам:** «Основные» (язык, открытие последнего воркспейса, автосохранение, колесо, групповая
  правка), «Внешний вид» (тема, масштаб, шрифты, миниатюры, фон просмотра), «Маски» (палитра, прозрачность
  оверлея), «Горячие клавиши».
* **Горячие клавиши:** таблица всех действий по разделам, поле записи сочетания, «↺» — по умолчанию,
  «Все по умолчанию», поиск; одинаковые клавиши у разных действий подсвечиваются. Удержание Z / X — тоже
  переназначается; [ ] и Shift+[ ] кисти — физические клавиши, показаны для справки.
