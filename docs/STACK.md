# Стек и фреймворки Image ColorMatcher

Версии — установленные в `python-embed` на 2026-10-01 (минимальные — в `requirements.txt`).

## Язык и среда

* **Python 3.12.8** — встроенная сборка `python-embed` (переносной Python рядом с программой, без установки
  в систему); зависимости: `python-embed\python.exe -m pip install -r requirements.txt`.
* **Windows 10/11** — основная платформа.

## Интерфейс

* **PySide6 6.11** (Qt 6) — весь GUI: главное окно с док-панелями, ленты миниатюр, дерево воркспейса,
  просмотрщик на `QGraphicsView` (зум, шторка, рисование масок), свои виджеты-ползунки с градиентной
  подложкой, `QUndoStack` (отмена), `QThreadPool` (фоновая загрузка и расчёты).
* **Темы** — 17 тем в JSON → Qt Style Sheets (QSS), `gui/theme.py`.
* **Локализация** — свой модуль `gui/i18n.py`: `tr()`, языки в JSON (`gui/lang/`, английский и русский; свои —
  в `%APPDATA%/colormatcher/lang`), смена языка на лету. Подробно — [I18N.md](I18N.md).
* **Горячие клавиши** — свой реестр действий `gui/shortcuts.py`: переназначение, конфликты, сброс.

## Обработка изображений

* **NumPy 2.5** — вся математика цвета и фильтров.
* **Numba 0.67** (llvmlite 0.49, LLVM) — JIT-ядро применения 3D LUT к картинке (быстрое превью и экспорт).
* **OpenCV 5** (`opencv-python-headless`) — масштабирование кадров и масок, быстрое float → uint8.
* **Pillow 12** — чтение и запись JPEG / PNG / TIFF / WebP, 16 бит, EXIF, ICC-профили.

## Данные и настройки

* **Pydantic 2.13** — модели: воркспейс, стеки правок, слои меток, пресеты, профиль пипетки, настройки
  авто-баланса и программы; валидация и миграции схемы.
* Форматы:
  * `*.cmws` — воркспейс (JSON, атомарная запись + `.bak`, пути относительно файла);
  * `<имя>.masks/<id>.npz` — маски-метки (сжатые веса uint8 H×W×9);
  * `*.cmpreset.json` — пресеты; темы и языки — JSON;
  * `%APPDATA%/colormatcher/settings.json` — настройки программы.

## Командная строка (бэкенд)

* **Typer 0.27** — CLI `colormatch` (фильтры, подбор, воркспейсы, экспорт, упаковка) — [CLI.md](CLI.md).
* **Rich 15** — таблицы, цвет и прогресс в консоли.
* `concurrent.futures` — пакетная обработка в нескольких процессах.

## Алгоритмы (своя реализация)

* Фильтры, откалиброванные по **Photoshop 25.6**: Color Balance, Brightness/Contrast, Hue/Saturation, Opacity
  (среднее отличие ΔE ≈ 0.03) — [ALGORITHM.md](ALGORITHM.md), [CALIBRATION.md](CALIBRATION.md).
* Стек правок → **3D LUT** (33³ превью, 65³ экспорт), трилинейная интерполяция.
* **Пипетка:** нейтральные пиксели по тонам (тени/середины/света), голосование плиток, Lab (CIE).
* **Авто-баланс:** Левенберг–Марквардт по реальным ползункам, L2 + L1-разреженность (IRLS), пределы,
  целые значения как в Photoshop.
* **Маски:** мягкая кисть «капсулами», веса меток, параллельный композит слоёв (`render_masked`),
  подбор слоя метки по распределению цвета области — [MASKS-DESIGN.md](MASKS-DESIGN.md).

## Тесты и качество

* **pytest 9.1** — ~150 тестов, включая GUI в режиме offscreen (`QT_QPA_PLATFORM=offscreen`).
* `tools/i18n_check.py` — полнота перевода и отсутствие необёрнутых строк.
* Проверка интерфейса — скриншоты без показа окна (`tests/_out/shot_*.py`).

## Инструменты вокруг

* **Калибровка по Photoshop:** скрипт ExtendScript (`tools/ps_calibrate.jsx`) строит эталонные слои в Photoshop;
  `tools/make_calibration.py`, `tools/fit_calibration.py`, `tools/compare_ps.py` — генерация, подгонка, сверка.
* **`ColorMatcher.exe`** — постоянная обёртка-запускатель на **C#** (`tools/launcher/ColorMatcher.cs`),
  компилируется встроенным в Windows `csc` (.NET Framework 4): `tools/build_launcher.bat`.
* **Windows Shell через `ctypes`** (`gui/winshell.py`): AppUserModelID и свойства окна для закрепления на панели
  задач со своей иконкой.
* **Иконка:** `tools/make_icon.py` (вырезка луны из `icon.jpg` → PNG/ICO).
* **Процесс:** Git (ветки по этапам), тикеты IDE в `.cuteide/tickets/`, документация в `docs/`.

## В планах, пока не используется

* **onnxruntime** — нейросети (сегментация неба/кожи, карта глубины) для помощников масок — [ML-ANALYSIS.md](ML-ANALYSIS.md).
* LLM и визуальные модели — по итогам анализа для балансировки не нужны.
