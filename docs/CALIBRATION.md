## Найденные законы Photoshop

**Все три фильтра — поканальные или HSL-поточечные и НЕ зависят от содержимого кадра**
(проверено: выход канала не зависит от других каналов; Brightness/Contrast на тёмном и
светлом реальном фото дал ту же кривую, что и на HALD, до 0.002).

### Color Balance = «Уровни» по каналам

Каждый канал: точка чёрного B, белого W, гамма γ; `y = ((x − B)/(W − B))^γ`.
Ползунок v на оси канала ch (cr→R, mg→G, yb→B), a = |v|/255:

| | Preserve Luminosity ВКЛ | ВЫКЛ (только свой канал) |
|---|---|---|
| тени, v > 0 | B других двух += a | γ своего ×= 2^(−v/200) |
| тени, v < 0 | B своего += a | B своего += a, γ своего ×= 2^(−v/200) |
| середины | γ своего ×= 2^(−v/200), других ×= 2^(+v/200) | γ своего ×= 2^(−v/100) |
| света, v > 0 | W своего −= a | W своего −= a, γ своего ×= 2^(−v/200) |
| света, v < 0 | W других двух −= a | γ своего ×= 2^(−v/200) |

Сочетания: B и W складываются, гаммы перемножаются (сочетания сходятся до 0.0001).
Гамма < 1 у PS имеет «носок» у чёрного (x < ~0.13): конечная крутизна вместо
бесконечной — поправка табличная (`gamma_toe`, по γ = 2^−0.5 и 2^−1).

### Brightness/Contrast

* Порядок: сначала яркость, потом контраст (обратный порядок ошибается на 0.05).
* Яркость b > 0: в тенях `y ≈ k·x`, `k = e^(0.0063·b)` (+50 → ×1.37, +150 → ×2.57), к светам
  плавно к 1: `y = kx / (1 + (k^p − 1)x^p)^(1/p)`, p ≈ 4–6 по узлам + табличный остаток.
* Яркость b < 0 — **обратная функция** к +|b| (совпадение до 0.0002).
* Контраст: `y = x + (c/100)·D(x)`, **линеен по c** в обе стороны (−50 — зеркало +50),
  профиль D снят с c = +100.
* Legacy: яркость — сдвиг на b/255; контраст — растяжение вокруг 127/255 с клиппингом,
  наклон 1 + c/100 (c < 0) или 1/(1 − c/100) (c ≥ 0).

### Hue/Saturation (Master)

* Порядок: **сначала светлота**, затем тон и насыщенность (обратный — ошибка до 0.23).
* Светлота: v < 0 — `rgb·(1+v)`, v > 0 — `rgb + (1−rgb)·v`.
* Тон — поворот HSL-тона.
* Насыщенность в HSL при сохранении HSL-светлоты: v < 0 — `S·(1+v)`, v > 0 — `S/(1−v)`
  с обрезкой до 1 (+100 → любой не серый цвет полностью насыщен).

### Opacity

Смешение с оригиналом в обычных (гамма-кодированных) значениях RGB — как у нас
(в линейном свете ошибка была бы 0.045).

### Наблюдения на серой шкале (r = g = b)

**Color Balance, тени cr +100:**

| вход | 0.127 | 0.254 | 0.381 | 0.508 | 0.635 | 0.762 | 0.889 |
|---|---|---|---|---|---|---|---|
| PL выкл: R | 0.231 | 0.378 | 0.504 | 0.619 | 0.725 | 0.825 | 0.920 |
| PL выкл: G = B | без изменений | | | | | | |
| PL вкл: R | без изменений | | | | | | |
| PL вкл: G = B | 0 | 0 | 0 | 0.191 | 0.399 | 0.608 | 0.817 |

* **PL выкл.** PS поднимает «свой» канал (R) по гладкой кривой, которая затухает к светам.
  Похоже на нашу модель по смыслу, но форма другая.
* **PL вкл.** PS не поднимает R, а опускает G и B как «Уровни» с точкой чёрного
  **100/255 = 0.392**: `G' = (G − 0.392) / (1 − 0.392)` — совпадает до 3-го знака.
  Сохраняется **максимум каналов**, а не средняя яркость: сдвиг теней в красный с PL
  делает тени темнее и краснее. В нашей модели (HSL-светлота) этого нет — переписать.
* Вывод: Color Balance в PS ближе к **поканальным «Уровням»/кривым**, чем к модели GIMP.
  Модель будем строить как 3 кривые на канал (по значению самого канала), параметры
  которых зависят от 9 ползунков. Подгонять — по полному набору (±50, ±100, сочетания).

**Brightness/Contrast, яркость +50** (одинаково на R, G, B):

| вход | 0.127 | 0.254 | 0.381 | 0.508 | 0.635 | 0.762 | 0.889 |
|---|---|---|---|---|---|---|---|
| PS | 0.174 | 0.348 | 0.522 | 0.678 | 0.804 | 0.901 | 0.967 |
| наша гамма | 0.232 | 0.379 | 0.505 | 0.619 | 0.725 | 0.825 | 0.920 |

PS в тенях почти линейно умножает яркость (~×1.37), к светам плавно сходит к 1.
Наша гамма-кривая сильнее поднимает глубокие тени и слабее — середину. Форму кривой
подгоняем по 8 значениям яркости из полного набора.

**Hue/Saturation, насыщенность +50:** на тёплых цветах совпадение почти точное
(красноватый `(0.635, 0.317, 0.317)`: PS `0.792/0.160`, мы `0.794/0.159`). На синих PS
сильнее дотягивает ведущий канал до 1 (`(0.317, 0.476, 0.794)` → PS B = 1.0, мы 0.897).

**Opacity 50%** — проверим после полного набора (нужен тот же сочетательный файл на 100%).
