# Локализация интерфейса (T-0083)

Языки: **английский** (по умолчанию) и **русский**. Язык выбирается в «Настройки → Основные → Язык»
и применяется сразу после закрытия окна настроек, без перезапуска (T-0086).

## Как устроено

* Строки интерфейса пишутся в коде на исходном языке (русском) и оборачиваются в `tr()`
  (`colormatcher/gui/i18n.py`):

  ```python
  tr("Открыть…")                         # "Open…" в английском
  tr("Открыт {name}", name=path.name)    # подстановки — по имени, после перевода
  plural(n, "папка", "папки", "папок")   # формы слова тоже переводятся; не-русские языки — «одна / много»
  ```

* Подписи из ядра (названия фильтров и параметров, оси Color Balance, палитры, служебные метки,
  названия тем) переводятся в момент показа: `tr(flt.label)`.
* Файлы языков — JSON:

  ```json
  {"meta": {"code": "en", "name": "English"},
   "strings": {"Открыть…": "Open…", "Открыт {name}": "Opened {name}"}}
  ```

  * встроенные — `colormatcher/gui/lang/*.json`;
  * свои — `%APPDATA%/colormatcher/lang/*.json` (или `$COLORMATCHER_HOME/lang`); свой файл с тем же кодом
    дополняет/перекрывает встроенный.
* Нет перевода строки — показывается исходная. `ru.json` — исходный язык, строк в нём нет.

## Как добавить язык

1. Скопируйте `colormatcher/gui/lang/en.json` в `<код>.json` (например `de.json`) — в `%APPDATA%/colormatcher/lang/`
   или рядом с встроенными.
2. Поменяйте `meta`: `{"code": "de", "name": "Deutsch"}`.
3. Переведите **значения** (английский текст справа); ключи (слева) не трогайте. Подстановки `{name}` сохраните.
4. Выберите язык в настройках и перезапустите программу.

## Проверка

`python tools/i18n_check.py` — строки без перевода в `en.json`, лишние ключи и русские строки в GUI,
не обёрнутые в `tr()`; `--stub` дописывает недостающие ключи с пустым переводом. Тот же контроль — в
`tests/test_i18n.py`.

CLI пока не локализован (сообщения — на русском).

## Смена языка на лету (T-0086)

Строки берутся через `tr()` при построении виджетов, поэтому при смене языка главное окно **пересобирается**
(`MainWindow.switch_language`): новое окно получает тот же `AppState` (воркспейс, путь, история Undo, выделение,
текущее фото, активный слой) и тот же кеш картинок, режим просмотра, папку ленты, геометрию и раскладку
панелей; старое окно отписывается от сигналов состояния и кеша и закрывается без вопросов о сохранении.
